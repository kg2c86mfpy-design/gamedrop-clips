# Music library — all public domain (CC0), from FreePD.com
FreePD closed; originals archived at https://archive.org/details/freepd (category folders). No attribution required, no credits spent.
Each file = 45 s starting at the track's hook (intro skipped, see tracks.json), loudness-normalised to -14 LUFS.
Copy to remotion/public/music/ and pass the file name as `music` (MemeTwoBeat, TierList) — plus `punchMusic` on MemeTwoBeat for a beat switch on the punch.
